# SafePaste

**SafePaste** is a zero-dependency, 100% browser-based privacy scrubber that removes sensitive personal data from text before you paste it into AI tools.

## What It Redacts Automatically
- Email addresses (`[REDACTED_EMAIL]`)
- Phone numbers (`[REDACTED_PHONE]`)
- IPv4 addresses (`[REDACTED_IP]`)
- Credit card / long ID numbers (`[REDACTED_CARD_OR_ID]`)
- Common API keys (`[REDACTED_API_KEY]`)

## Why SafePaste?
Everything runs locally inside your browser. Zero servers, zero tracking, and zero installation required.

## How to Use
1. Open the live GitHub Pages link for this repository.
2. Paste your raw text, email, or log file.
3. Click **Scrub Sensitive Data**, then click **Copy Clean Text**.
